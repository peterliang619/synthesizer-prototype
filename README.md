# Synthesizer Prototype

An interactive synthesizer with 40 pressable keys.

## Features

- 40 pressable keys (key1-key40)
- White background
- 2px downward shift animation when keys are pressed
- Touch and mouse support
- Responsive design

## Usage

Simply open `index.html` in a web browser. Click or touch any of the 40 keys to interact with them.

## Files

- `index.html` - Main synthesizer interface
- `synthesizer svg` - SVG file with synthesizer graphics
